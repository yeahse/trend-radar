## 3. 셋팅 체크리스트 (구체적)

### A. ★ 채널 기본 언어 = Thai (가장 중요)
`YouTube Studio → 설정 → 채널 → 기본 언어` → **Thai (태국어)**
`다른 언어 추가` → **한국어, 영어, 일본어**

**왜:** 유튜브 검색·추천 시스템이 채널 언어를 본다. 한국어 채널은 태국 추천 풀에 안 들어간다.
(위키|Univ of Michigan 연구: *"YouTube recommendations can sideline heritage-language content"* — 언어 불일치 콘텐츠는 추천에서 밀려남)

### B. ★ 영상 단위 다중언어 (공식 지원 기능)
`Studio → 영상 → Subtitles → ADD LANGUAGE → Thai`
- Title & description **번역** 입력 → PUBLISH
- 롱폼은 **썸네일도 언어별** 업로드 가능
- → **태국어 제목/설명/썸네일이 검색 스니펫에 노출**

### C. ★ 자동 더빙 (auto-dubbing) 태국어
Studio → 영상 → **Dubbing → Thai**. 생성된 태국어 오디오가 **뷰어 선호 언어 기본 재생**이 됨.
→ 한국 원곡 + 태국어 더빙 트랙 2개가 붙음 = **태국 시청자 retention 유지**

### D. 자막
- 태국어 수동 자막 필수 (자동 자막은 태국어 품질 낮음)
- **자막은 두 번째 트랙** (번역+원어) — 태국 시청자는 자막 없으면 이탈

### E. 제목 / 설명 (태국어 우선)
```
제목: [태국어 훅] + 한국어 원제 병기
설명 첫 2줄: 태국어 요약 (검색 스니펫에 이것만 노출)
해시태그: 태국어 일반어 3개 + #TSMalfoy 같은 로컬 태그
```
- **"Malfoid" 대신 "Draconia" 사용** (위키피디아 표준명 + 인셀슬러 'foid' 리스크 회피)
- 태국어 번역은 기계번역 후 태국인 자연어 확인 필수 (직접 타이landers 대상 노출이라 번역 품질이 곧 CTR)

### F. 썸네일 (태국 최적화)
- **태국어 텍스트 크게** (영문 텍스트보다 태국어 스크립트가 태국 피드에서 구분됨)
- 얼굴 + 대비 강하게, 모바일에서 읽히는 크기
- 참고: 스프링거 논문 *"YouTube thumbnail design recommendation systems … specifically focusing on YouTubers in Thailand"* (food/IT/travel 3분류, 88% 정확도 — 태국 썸네일은 카테고리 정서로 구분됨)

### G. 업로드 시간 (태국 현지 UTC+7)
- **우선순위 1: Studio → 분석 →'audience' → "When your viewers are on YouTube" 하트맵** (로컬시각 표시) → 거기에 맞춰 올리기
- 일반 가이드(현지시각): **숏폼 12–3시 / 7–10시**, **롱폼 오전 8–11시**
- 태국 소비층 = 이동·화장시간(7–9시), 점심(12–14시), 저녁(19–22시) 3봉우리

### H. 포맷 결정
| | 태국 실측 | 권장 |
|---|---|---|
| 롱폼 | 태국 평균 길이 **42:22** | 롱폼 소비됨 → **3~8분 단편 + 20분+ 본편** 둘 다 |
| 숏폼 | tag국 top10의 44%가 Gaming | **세로 9:16 숏폼**, 주 5~7개 |
| 밸런스 | — | 롱폼 주 2~4개 + 숏폼 주 5~7개 (Buffer/Metricool 2026 데이터) |

### I. 엣지 체어
- 태국어 카테고리 설정, 태국어 해시태그
- **태국어 고정댓글** (질문形式 → 알고리즘 상호작용)
- 커뮤니티 포스트(태국어)로 예고 → 구독 유도
- 라이브: 태국 시간대 21시(커뮤니티 함성 시간)

### J. 분석 체크 (매주)
`Studio → 분석 → 타겟 국가 = 태국` → **观众的地理分布에서 태국 비중 추적**
→ 태국 시청자 %가 오르면 채널 언어를 Thai → 한국어 순으로 조정

## 6. 실행 순서 (1주)

1. Studio → 채널 기본 언어 Thai + 한국어/영어/일본어 추가
2. 기존 영상 10개 → Thai 제목/설명/썸네일 번역 추가 + Thai 자막
3. 신영상 3편 → Thai 더빙 + Thai 자막 + Thai 썸네일 + Thai 고정댓글
4. Shorts 5개 (K-pop 퍼포먼스 스타일) → 태국시간 12–3시 / 19–22시
5. Studio 분석 → 타겟 국가 태국 비중 확인 → 주간 조정
6. **A/B**: 원본(한국어) vs 태국어 버전 → 48시간 후 CTR/ retention 비교
