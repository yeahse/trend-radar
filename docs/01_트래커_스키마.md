# 트래커 스프레드시트 — 스키마와 운용법

## 1. 두 가지 방식

### A) Google Sheets (권장)

1. https://sheets.google.com → 새 스프레드시트
2. `data/tracker_YYYY-MM-DD.csv` 업로드 (UTF-8 BOM 포함이라 한글 자동 인식)
3. 시트 3개로 구성:

| 시트 | 용도 | 주기 |
|---|---|---|
| `RAW` | 매일 쌓이는 수집 원본 | 자동 (CSV) |
| `TRACK` | 내가 관리하는 판단·제작·성과 | 수동 |
| `LOOKUP` | watchlist & fit 키워드 | 수동 (config와 동기화) |

### B) Notion

- Notion → Settings → Import → CSV 업로드 (데이터베이스 생성)
- 속성 매핑: `term`(Title), `score`(Number), `action`(Select: ACT/WATCH/IGNORE), `date`(Date) 등
- Notion 자동화(또는 Make/Zapier)로 `action=ACT` 인 행을 Discord/Slack으로 푸시

## 2. TRACK 시트 컬럼 정의

| 컬럼 | 타입 | 설명 | 예시 |
|---|---|---|---|
| `date` | 날짜 | 수집일 | 2026-10-22 |
| `term` | 텍스트 | 감시 키워드 | 말포이 |
| `score` | 숫자 | TrendScore (0~100) | 59 |
| `velocity` | 숫자 | 속도 점수 (0~100) | 54 |
| `crossPlatform` | 숫자 | 동시 등장 플랫폼 수 | 3 |
| `supplyDeficit` | 숫자 | 경쟁 공백 점수 (높을수록 경쟁 적음) | 75 |
| `fit` | 텍스트 | 내 포맷 적합 키워드 | genderbend |
| `redditHits` | 숫자 | 레딧 최근 7일 반응 수 | 12 |
| `blueskyHits` | 숫자 | 블루스키 반응 수 | 8 |
| `wikiGrowth` | 숫자(%) | 위키 7일 조회수 성장률 | 120.5 |
| `ytUploads` | 숫자 | 최근 7일 해당 키워드 영상 수 (키 있으면) | 2 |
| `sources` | 텍스트 | 근거 링크 (| 구분) | https://... |
| `action` | Select | ACT / WATCH / IGNORE | ACT |
| `note` | 텍스트 | 메모 | "원작 크레딧 확인" |
| `videoUrl` | 텍스트 | 실제 올린 영상 URL | https://youtu.be/... |
| `publishedAt` | 날짜/시간 | 업로드 시각 | 2026-10-23 10:00 |

> `action`부터 `publishedAt`까지 4개는 **CSV 자동 수집이 아니라 네가 직접 채우는 칸**이다.
> 이 4칸이 있어야 "예측 → 실행 → 회고" 루프가 돌아간다.

### 추가 권장 컬럼 (수동)

| 컬럼 | 설명 |
|---|---|
| `production_hours` | 제작에 걸린 시간 → **제작속도 = 진입장벽** 측정 |
| `views_24h` / `views_7d` | 업로드 후 조회수 |
| `subs_gained` | 구독자 증가 |
| `hit` | Y/N (예측 적중 여부) → 월말 정확률 계산 |

## 3. 운용 순환

```
[수집]  node src/run.mjs
   ↓
[판정]  TRACK 시트 action 칸 기입 (ACT/WATCH/IGNORE) — 30초
   ↓
[제작]  ACT → 48시간 안에 1화. note에 제작 예상시간
   ↓
[배포]  videoUrl / publishedAt 기록
   ↓
[회고]  views_7d, subs_gained, hit 기록 → 다음 주 판정에 반영
```

### 판정 기준 (숫자로)

| action | 조건 | 행동 |
|---|---|---|
| **ACT** | score ≥ 55 AND 공급(최근 업로드) ≤ 8편 | 48시간 안에 1화 확정 |
| **WATCH** | score ≥ 35 | 7일 뒤 재확인, 알림만 |
| **IGNORE** | score < 35 또는 1개 플랫폼만 등장 | 무시 |

### 후회 방지 규칙

1. **Breakout은 1편만.** 구글트렌드 Breakout(5000%↑)은 fad 확률 90%. 1편 찍고 조회수·구독자 반응 보고 확장.
2. **같은 밈에 2편 연속 올리지 말 것.** 1부는 "한 편만", 2부는 "확장편"으로 5~7일 간격.
3. **공급이 늘면 즉시 중단.** 같은 키워드 영상이 7일 안에 15편 넘어가면 그쪽은 이미 늦음.
4. **적중/실패 반드시 기록.** 30건 쌓이면 내 예측 정확도가 숫자로 보인다. 그게 실력이다.

## 4. 월간 회고 (월 1회 30분)

- [ ] ACT 중 실제 트래픽을 얻은 비율 = **적중률**
- [ ] 적중한 밈의 공통점: (원작 IP? 포맷? 한국어 미검색?) → 다음 탐색 우선순위 수정
- [ ] 놓친 밈: 왜 놓쳤나 (어느 티어에서 못 봤나) → 감시 대상 추가
- [ ] `production_hours` 평균 → 제작속도가 진입장벽으로 작동하는지 확인
- [ ] watchlist 정리: 90일 연속 0 반응인 키워드 삭제
