# 무료 툴 세팅 가이드 — 0부터 순서대로

> 목표: **하루 20~25분**이면 "내 채널에 지금 들어올 수 있는 유행"을 2~4주 먼저 본다.
> 전부 무료. 유료는 마지막에 선택지로만.

---

## STEP 1. (5분) vidIQ 브라우저 확장 — 유튜브 네이티브 조기탐지

가장 먼저 세팅. 말포이가 "유튜브에서 터질 때"를 가장 빨리 잡는 곳.

1. Chrome/Edge 확장 설치: **vidIQ** (무료)
2. 로그인 (구글 계정)
3. 좌하단 **"Trending Keywords"** 페이지 → `vidiq.com/trending-keywords`
   - **Updated every 6 hours** — 6시간마다 갱신
   - 각 키워드의 **Average views per hour** = 시간당 조회수 = 가장 빠른 선행지표
   - "Similar keywords" 로 변형 클러스터 확인 (예: `tesla fly` / `tesla flying` / `flying tesla`)
4. **Trend Alerts** 설정 (무티 이어폰 가능):
   - 대상 키워드: 내 watchlist + IP명 + 포맷어
   - 기준: **views per hour 임계값** (예: 50K 이상)
   - 알림 빈도: Daily
5. **Outliers** 기능 ON — 내 채널 최근 업로드 중 평균 outperform 영상 자동 표시

> 왜 이게 1순위인가: 검색량은 "이미 생긴 수요"를 알려주고, views/hr은 "지금 막 만들어지는 영상"을 알려준다. 알고리즘은 공급량을 본다.

**내 채널에 적용**: 같은 키워드에 경쟁 채널이 몇 편이나 올렸는지 vidIQ "Competitors Scorecard"에서 확인. **0~2편이면 공짜 시장**.

## STEP 2. (10분) 네이버 데이터랩 — 한국 수요 (키 필요 없음)

1. https://datalab.naver.com/keyword/trendSearch.naver
2. 주제어 1: `말포이` / 하위: `말포이,말포이TS,말포이AI,TS말포이`
3. 주제어 2: `해리포터AI` / 하위: `해리포터AI,해리포터 AI팬애니,해리포터팬애니`
4. 기간: **1개월**, 일간 → 조회
5. **다운로드** 버튼 → xlsx (내 스크립트가 이걸 자동으로 긁음)

읽는 법:
- 그래프 최댓값 = 100 (기간 내 상대값)
- **10월 초에 100 찍고 10월 중순에도 60~70이면 = 아직 살아있는 판.**
- 말포이 7일 성장률이 -50%면 이미 늦은 것, ±0%면 계속 opportunities 있음.

> ⚠️ 네이버 **실시간 급상승 검색어(실검)는 2021년 말 폐지**됐다. 대체는 데이터랩 + 네이버 앱 내 인기 검색어.

## STEP 3. (10분) TikTok Creative Center — 포맷 트렌지

1. https://ads.tiktok.com/business/creativecenter
2. **Trends → Hashtags** → 지역 `Korea` / 기간 `Last 7 days`
3.排行 확인: 포스트 수 + 뷰 수 + "Trends" 탭의 변화 곡선
4. 같은 화면 **Songs** 탭에서 음악 트렌드, **Creators** 탭에서 새로 떠오른 크리에이터

읽는 법 (이게 핵심):
- **포스트 수 대비 뷰 수가 높으면** = 아직 경쟁이 적고 소비가 붙은 상태 → 진입 구간
- 7일 vs 30일 그래프가 **계속 올라가면** = 확산 중
- 예시(2026-10-22 실측): 미국 7일 1위 `#tiktokscaryhorrorcontest` = 312M 뷰 → **AI/소품 형식의 공상 horror 숏폼 챌린지**가 폭발 중. 한국 7위는 `#한글날`(11월 seasonally), `#모몽가`(국내 밈 캐릭터), `#스토리타임`.

> 로그인 없이 3개까지만 보인다. 전체 Top 100은 로그인 필요(무료).

**포맷 트렌드가 개별 밈보다 중요**: `#tiktokscaryhorrorcontest` 같은 챌린지 포맷은 "어떤 IP든 그 포맷에 넣으면 터진다" → 다음 밈을 만드는 내 공장.

## STEP 4. (5분) Know Your Meme — 밈의 탄생

1. https://knowyourmeme.com/trending
2. **새로 추가된 엔트리**만 체크 (기존 밈 재조회 ❌)
3. 엔트리 들어가서 **"Under Research"** 표시 = 아직 확정 전 = 지금이 기회
4. Origin 탭의 **날짜** = 최초 폭발일. 여기서 3~7일이 내 진입 구간

> 말포이 사례: KYM 최초 보도 2026-09-30(Under Research) → 한국 콘텐츠는 10월 중순. **원천지 대비 4주 늦으면 이미 늦은 것.**

## STEP 5. (10분) Reddit / Bluesky — 크로스오버 감지

**Reddit** (무료)
1. https://www.reddit.com/prefs/apps → "script" 앱 생성 (무료) → client id/secret 복사
2. `config.json`의 `reddit.clientId` / `clientSecret` 에 붙여넣기
3. 감시 subreddit 예시: `dankmemes`(만체页), `HarryPotter`, `genderbent`, `rule63`, `MALfoid`, `Animemes`, `CharacterDesign`
4. **검색 RSS는 IP당 1회만 성공**한다. OAuth 키를 넣으면 해결됨.

**Bluesky** (키 불필요)
- https://bsky.app 에서 팔로우 → 팬덤 아티스트 팔로우
- API로도 검색 가능: `https://api.bsky.app/xrpc/app.bsky.feed.searchPosts?q=malfoid`
- **팬덤은 X→블루스키로도 이동한다.** 말포이 논쟁도 블루스키에서 먼저 터졌다.

**핵심 판단**: "원래 있던 팬덤 서브레딧"이 아니라 **만체 subreddit(r/dankmemes 같은)에 진입하면 = 메인스트림 진입 = 유튜브 해설/AI영상 제작阶段가 온다.**

## STEP 6. (5분) Google Trends — 검증 (탐색 아님!)

1. https://trends.google.com/trends/explore
2. 내 watchlist 키워드 + `date=today 3-m`, geo `South Korea`
3. **Related queries → Rising** 탭 (Top이 아니라 Rising!)
4. **"Breakout"(5,000%↑) = fad 확률 높음** → 영상 1편만 테스트
5. **持续的 growth(60~250%) = 구조적 변화** → 채널 자산

구글트렌드는 **탐색이 아니라 검증**이다. "이거 진짜일까?"를 확인할 때만 쓴다.

> 2026-10-22 실측 예시: `말포이` 한국 검색은 10/7 피크(100) 후 10/21에도 71.4 유지. `해리포터`는 +18.2%로 원작 IP 자체가 지금 상승 중 → **TS/파생 콘텐츠 여지가 아직 살아있다**는 뜻.

## STEP 7. (5분) 알림 세팅 (이게 있어야 "미리" 알 수 있다)

| 도구 | 하는 일 | 링크 |

| **Talkwalker Alerts** | 구글알erts보다 낫고 소셜 포함 | talkwalker.com/alerts |
| **Google Alerts** | 최简单 | google.com/alerts |
| **Feedly** | RSS 폴더 | feedly.com |
| **Distill.io / ChangeDetection.io** | 페이지 변경 감지 (무료) | distill.io |

등록할 키워드 예시:
```
말포이, malfoid, fem draco, female draco, TS 말포이,
AI 팬애니, AI 판애니, AI fan animation, genderbend, rule 63,
그리고 "내가 감시할 IP 이름" + "female version" / "gender swap"
```

> 말포이로 치면 9/22~9/23에 알림이 왔어야 한국 콘텐츠를 10월 초에 올릴 수 있었다.
