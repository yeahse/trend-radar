## ① 08:30 — 자동 (네가 안 건드려도 됨)

### ⚠️ 자동 실행 방식이 바뀜 (2026-10-24)
이 머신의 **Windows Task Scheduler가 어떤 태스크도 실행하지 못한다.**
(trivial 액션 `cmd /c echo probe > file` 로도 `LastRunTime` 갱신 안 되고 `LastTaskResult=267011`로 남음 → 머신 레벨 문제, 관리자 권한 필요해 우회 못 함)
→ **Task Scheduler 의존을 버리고 Startup 폴더 + 데몬**으로 대체했다.

| 항목 | 내용 |
|---|---|
| 등록 | `shell:startup\TrendRadar.cmd` → `tools\daemon.ps1` (로그온 시 자동 시작, 숨김) |
| 동작 | 5분마다 체크 → 08:30 지났고 오늘 미실행이면 수집 |
| **보정 실행** | PC를 껐다 켜도, 오전에 꺼져있었으면 **08:30 이후 첫 로그온에 자동 실행** |
| 즉시 실행 | `data\.run_now` 파일을 만들면 다음 체크(5분 내)에 즉시 1회 |
| 로그 | `logs\daemon.log` (데몬) · `logs\run.log` (수집) |
| 마커 | `data\.last_daily_run` (성공한 날짜) |

> Task Scheduler 태스크 `TrendRadar Daily`는 그대로 둔다. **재부팅 후 복구될 가능성**이 있어서.
> 데몬이 실패해도 스케줄러가 백업으로 돌면 이중 실행되지만, `data\.daemon.lock` + `data\.last_daily_run` 마커로 중복은 막는다.

## ③ 09:05 — record 1분 (★이게 제일 중요)

판단을 시스템에 남겨야 다음 주에 "맞았나"가 나온다. **이걸 안 하면 프로그램이 그냥 알림 봇이 된다.**

```powershell
cd "C:\Users\ue-agent\Documents\기본 프로젝트\trend-radar"

# 만들기로 함
node src/record.mjs --term "제비차" --status made --note "나법 타는 장면 1편"

# 포기로 함 (포기도 정보! 뭘 왜 안 했는지 남기면 다음에 안 proposing됨)
node src/record.mjs --term "female draco" --status skipped --note "FOYEGE가 이미 하는 중"

# 업로드 완료 (조회수도 나중에 채움)
node src\record.mjs --term "제비차" --status posted --url "https://youtu.be/xxx" --views 1234
```

| status | 뜻 |
|---|---|
| `made` | 만들기로 함 |
| `skipped` | 포기 (이유를 note에) |
| `posted` | 업로드 완료 (`--url`, `--views`) |

확인:
```powershell
node src\record.mjs --list    # 최근 기록
node src\record.mjs --stats   # 적중률
```
