# 일일 브리핑 자동화 — 3가지 방법

> 목표: **아침에 눈 뜨면 "오늘 뭘 만들지"가 자동으로 떠 있어야 한다.**

---

## 방법 1. Discord 웹훅 (가장 쉬움, 권장)

1. Discord 채널 생성 (예: `#트렌드`)
2. 채널 설정 → **Integrations → Webhooks → New Webhook** → URL 복사
3. `config.json`에 입력:
```json
"discord": { "webhookUrl": "https://discord.com/api/webhooks/..." }
```
4. `node src/run.mjs` 실행하면 자동 전송 (ACT 상위 5개 + 신규 발견 상위 5개)

확인: 브라우저에서 `https://discord.com/api/webhooks/<ID>/<TOKEN>` 열면 OK.

---

## 방법 2. 텔레그램 봇

1. @BotFather → `/newbot` → 토큰
2. 봇에게 `/new` → chatId 확보 (또는 채널에 추가하고 @botusername 멘션)
3. `config.json`:
```json
"telegram": { "botToken": "123456:ABC", "chatId": "987654321" }
```

---

## 방법 3. Windows 작업 스케줄러 (매일 자동 실행)

> ✅ **2026-10-23 이미 등록 완료.** 태스크명 `TrendRadar Daily`, 매일 **08:30**, `tools\run_daily.bat` 경유,
> `logs\run.log`에 exit code 기록. 로그 확인: `Get-Content "C:\Users\ue-agent\Documents\기본 프로젝트\trend-radar\logs\run.log" -Tail 20`
>
> ```powershell
> Get-ScheduledTask -TaskName "TrendRadar Daily"        # 등록 확인
> Start-ScheduledTask -TaskName "TrendRadar Daily"     # 지금 1회 즉시 실행
> ```

### Discord로 받는 모양 (2026-10-23 최종)

**Discord에는 🌍 글로벌 트렌드만 온다.** (2026-10-23 사용자 지시: "왜자꾸 해리포터섹션이 따로 딸려오냐" → 감시 키워드 블록을 Discord에서 제거)

| 메시지 | 내용 |
|---|---|
| **① 🌍 글로벌 트렌드** | 🧭 유행하는 미디어 형식(18종) · 🎯 지금 올릴 수 있는 것(직격 12건) · 🗺 국가별 급상승 (1/3·2/3·3/3) — 37개국 |
| **② ▶ 국가별 YouTube 인기 #1** (1/3·2/3·3/3) — 37개국 |

**감시 키워드(공급량·경쟁영상·적중률)는 리포트와 tracker CSV에만 있다.**
- `reports/YYYY-MM-DD.md` → `## 📌 내 감시 키워드 현황` 섹션
- `data/tracker_YYYY-MM-DD.csv` (전체 50위 랭킹은 `data/global_trends_YYYY-MM-DD.csv`, 2,700+행)

> Discord 총 6000자/메시지 한계 → embed 분할 + `trimEmbedsForDiscord()` 안전장치(초과 시 뒤 embed부터 제거)

별도 채널로 분리하려면 `config.json` → `discord.globalWebhookUrl` 에 웹훅 URL을 추가하면
글로벌 embed가 그 채널로만 간다 (비워두면 #briefing에 함께 전송).

**GUI로 다시 등록하고 싶을 때**
1. 작업 스케줄러 → "기본 작업 만들기" → 매일 → 시간(예: 08:30)
2. 동작: "프로그램 시작"
   - 프로그램: `C:\Program Files\nodejs\node.exe`
   - 인수: `"C:\Users\ue-agent\Documents\기본 프로젝트\trend-radar\src\run.mjs"`
   - 시작 위치: `C:\Users\ue-agent\Documents\기본 프로젝트\trend-radar`
3. 조건: "태스크가 실패하면 다시 시작" + 10분 간격 3회

**명령 프롬프트 방법** (`schtasks`)
```bat
schtasks /create /tn "TrendRadar Daily" /tr "\"C:\Program Files\nodejs\node.exe\" \"C:\Users\ue-agent\Documents\기본 프로젝트\trend-radar\src\run.mjs\"" /sc daily /st 08:30 /f
```

**PowerShell HiddenWindow 문제 해결**
```powershell
$action = New-ScheduledTaskAction -Execute "C:\Program Files\nodejs\node.exe" `
  -Argument '"C:\Users\ue-agent\Documents\기본 프로젝트\trend-radar\src\run.mjs"' `
  -WorkingDirectory "C:\Users\ue-agent\Documents\기본 프로젝트\trend-radar"
Register-ScheduledTask -TaskName "TrendRadar" -Action $action -Trigger (New-ScheduledTaskTrigger -Daily -At 8:30am)
```

> `tools/run_daily.bat`도 제공 — 더블클릭만으로 실행 + 로그 저장.

## 방법 4. n8n (무료, 시각적 자동화)

`tools/n8n_daily_briefing.json`을 n8n에 Import → 스케줄 트리거(매일 08:00) → HTTP Request로 로컬 스크립트 실행 → Discord 노드로 전송.

```
[Schedule Trigger] → [Execute Command: node src/run.mjs] → [Read reports/latest.md] → [Discord: Send Message]
```

n8n이 같은 PC에 없다면 Docker:
```bat
docker run -d --name n8n -p 5678:5678 -v %USERPROFILE%\n8n_data:/home/node/.n8n n8nio/n8n
```

## 방법 5. (추천 조합) 브라우저 콘솔 수집기

TikTok Creative Center, vidIQ, Google Trends처럼 **브라우저에서만 보이는 데이터**는 스크립트가 못 긁는다.
그때 쓰는 도구: `tools/browser_console_collector.js`

사용법:
1. 해당 페이지(예: TikTok Creative Center 해시태그 페이지) 열기
2. F12 → Console
3. 파일 내용 복사 붙여넣기 → Enter
4. JSON이 클립보드에 복사됨 → `data/manual_TIKTOK.json` 으로 저장
5. 스크립트가 이 파일을 읽어 리포트에 합침

> 이 방식이 필요한 이유: 틱톡/구글 내부 API는 시그니처가 필요해 자동화가 어렵다. 대신 "내가 1분만 클릭해서" 확보하는 게 오히려 빠르고 확실하다.
