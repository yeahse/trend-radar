## 2. Reddit OAuth (✅ 2026-10-24 해결 — 동작 중)

> 상세: `docs/06_Reddit_접근_현황.md`

### 결론
`prefs/apps` 의 "create an app" 은 **계정 문제가 아니라 Reddit 전역 정책 변경**으로 막혔다.
reCAPTCHA는 통과하지만 서버가 항상 아래를 반환한다:
```
In order to create an application or use our API you can read our full policies here:
.../42728983564564-Responsible-Builder-Policy
```

그래서 **동작하는 경로는 두 개**로 나눴다.

### 2-1. 지금 동작 중 — 공식 Devvit CLI 토큰 (키 입력 불필요)
Reddit **공식 CLI** `npx devvit login` 이 OAuth 토큰을 발급하고, 이 토큰은 `scope=*` 로
`oauth.reddit.com` 전체 접근 가능. 서브레딧 top + **검색** 둘 다 동작(실측 200).

```powershell
npx.cmd -y devvit@0.15.0 login    # 브라우저 승인 → ~/.devvit/token 저장
node tools\test_devvit_token2.mjs # /me 200 확인
```
`src/reddit_auth.mjs` 가 이 토큰을 읽고 **만료(24h) 임박 시 자동 갱신**한다.
→ 키 입력 없이 지금 바로 서브레딧 + 검색 + 크로스오버가 돈다.

### 2-2. 앞으로 — 정식 client id / secret (Data Access Request)
Reddit 정책이 지정한 유일한 정식 경로. **2026-10-24 티켓 접수 완료**
("Your request was successfully submitted." 확인)

승인 메일(treerahouse@gmail.com)이 오면:
1. **승인된 계정으로** https://reddit.com/prefs/apps 로그인
2. type **script** / name `trend-radar` / redirect uri `http://localhost:8080`
3. **Create app** → client id(`Reddit_xxxxxx`) + client secret 복사

### 넣는 곳
```json
"reddit": {
  "authMode": "auto",
  "clientId": "Reddit_xxxxxx",
  "clientSecret": "xxxxxxxxxxxxxxxx",
  "subreddits": [...],
  "queries": [...]
}
```
`authMode` 기본값 `auto` → classic 키가 있으면 우선 사용, 없으면 devvit 토큰 자동 사용.

### 뭐가 달라지나
| | 키 없음 (2026-10-23) | 현재 (devvit 토큰) | 정식 키 (승인 후) |
|---|---|---|---|
| 서브레딧 | top 3개만 (10개 중 3개씩 회전) | top 3개/회전 + **검색 1개/회전** | 동일 + 승인 상태 |
| **검색** | **불가** (RSS 검색은 무관 결과 반환 → 폐기) | **가능** = 크로스오버 밈 탐지의 핵심 | 동일 |
| 429 | 자주 발생 (IP당 쿼터) | 거의 없음 |
