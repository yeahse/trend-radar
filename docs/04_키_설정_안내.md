## 2. Reddit OAuth (⏳ 사용자가 직접 발급 필요)

### 왜 Aside 브라우저로 안 되는가
브라우저 콘솔에서 `fetch('https://www.google.com/recaptcha/api2/anchor')` → **Failed to fetch**
`fetch('https://www.recaptcha.net/recaptcha/api2/anchor')` → **Failed to fetch**
→ reCAPTCHA API 도메인이 이 브라우저 환경에서 차단되어 체크박스를 통과시킬 수 없다.
(일반 Chrome에서는 정상 동작)

### 발급 (1분)
1. https://www.reddit.com/prefs/apps → **"are you a developer? create an app..."**
2. type: **script** / name: `trend-radar` / redirect uri: `http://localhost:8080`
3. **Create app** → 아래에 표시되는 **client id**(`Reddit_xxxxxx`)와 **client secret** 복사

### 넣는 곳
```json
"reddit": {
  "clientId": "Reddit_xxxxxx",
  "clientSecret": "xxxxxxxxxxxxxxxx",
  "subreddits": [...],
  "queries": [...]
}
```

### 뭐가 달라지나
| | 키 없음 (현재) | 키 있음 |
|---|---|---|
| 서브레딧 | top 3개만 (10개 중 3개씩 회전) | 전부 + 매번 |
| **검색** | **불가** (RSS 검색은 무관 결과 반환 → 폐기) | **가능** = 크로스오버 밈 탐지의 핵심 |
| 429 | 자주 발생 (IP당 쿼터) | 거의 없음 |
